State Machines
- It is a reactive system
- Follows the Run-to-Completion. It cannot run another state transition until the current state transition is finish
- In programming, it must remember its current state like a state variable
- In making the state cases, at the default section, put it as an invalid because the transition did not meet any of the expected input to output outcome 
- For multiple input states, it can be nested switch case 
- State machine is most optimal to remember even the past states to do for the future states  ^iMNOvNyk
