For power loss, a solution is common journaled filesystems like ext4 ^jDtLqMrQ

NAND
How corruption can occur
- When writing, the entire memory block is erased to write
- if power is loss, the write will be fragment and also lose the parts that was erased ^GRtjAoOH

Solutions

1. Use read only root filesystem
- designed for files that are not meant to be changed to avoid corruption

2. System backup

3. Battery backup ^ZgUpHI9P

STM32 Protections ^dD0owiT1

Readout Protection

lvl 0
- no protection
- All R/W/Erase are permitted to flash

lvl 1
- If boot0 = 0 and no debugger, all R/W/Erase is permitted 
- if boot0 = 1 or debugger, all R/W/Erase to flash is blocked

lvl 2
- follow up from lvl 1
- boot from bootloader is not possible
- debugging i not possible
- no backdoor
- this is permanent ^b6R2imV8
