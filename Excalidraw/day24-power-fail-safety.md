Readout Protection

lvl 0
- no protection
- All R/W/Erase are permitted to flash

lvl 1
- If boot0 = 0 and no debugger, all R/W/Erase is permitted 
- if boot0 = 1 or debugger, all R/W/Erase to flash is blocked

lvl 2
- follow up from lvl 1
- boot from bootloader is not possible

What does atomic mean for a flash write?
- all or nothing. You write and it is there or fail and nothing stays ^mq6DS7ug

Why a sequence number?
- Since to write on flash, everything must be erased first. A sequence number is used to determine the record that is latestly valid ^ssjKNK3C

What is wear leveling?
- it is a technique to extend the lifespan of memory by distributing the write and erase cycles across all available blocks
- A flash can only handle a number of program cycles before the silicon layer degrades
- Wear leveling is an algorithm that prevents premature burnout by spreading the write operation. Pingpong/ Sector swapping, it alternates between page 1 and page 2 instead of blasting writes in a single address. The write toggles back and forth cutting the frequency per page in half  ^X627lA1y
