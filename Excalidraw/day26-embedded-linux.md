Task is essentially to create a linux machine like RTOS for Embedded. It can be a custom one. Linux is the top OS with RTOS and bare metal to follow

linux cant be done on the STM32F103C6T6 due to the limited ROM and RAM but it can still be learned enough. Just learning how to build one which is why this task will use a VM for the build  ^ncBzCgh0

1. Download the buildroot github repo

2. Go to /buildroot/configs to find the board. If board is not there, find one made online. I chose the stm32mp157a_dk1_defconfig

3. Run this inside the root folder of buildroot: make stm32mp157a_dk1_defconfig

4. make menuconfig: this will show the GUI of the stuff to customize on the image 

5. Once config is done, edit and type "make" to make the image (it takes a long time)

6. Once build is done, it is located in output/images/

6. sdcard.img can be copied and stored in an sdcard to make the linux image 
 ^xn5e9wBc

Putting the SD card to the IoT

1. Plug the SD card to the board 

2. Switch Boot 0 and Boot 2 to on to boot from the SD card 

3. connect the board to a serial terminal like picocom

4. The terminal should show the bootloader thingy like the setup and logger. Similar to how I do with creating a linux machine on this PC with debian, arch, cachyOs and currently NixOS

5. It should show a login prompt (everything works)

6. It should run like any linux machine ^fsEVLjkh

What are the parts of an embedded Linux system?
- bootloader
- Linux kernel: manages hardware resource, CPU scheduling, and drivers
- Root filesystem: /bin, /etc, /lib, /var
- Application Layer: ls, cp, grep, mount commands  ^SPQ5jn40

what does a device tree do?
- these describe the hardware components of a computer. Manages the processor, storages, peripherals, clocks, any hardware parts ^C8p2Vzkw

Why Cross Compile?

So the purpose of cross compile here means is to compile/ create the image in PC and the binaries are put in the IoT since IoT are a smaller version of a PC. They may handle the compiling but is slow. ANd the purpose of an IoT is usually to do only 1 job ^Ccnh0RnC
