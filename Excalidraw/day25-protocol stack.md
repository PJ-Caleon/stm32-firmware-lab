# Excalidraw Data

## Text Elements
Protocol Stack

1. Payload Generation (Host & MCU)
- a packet structure with message type, sequence number, length specifier and data payload

2. Data Integrity (CRC16-CCITT)
- checksum that validates every received byte stream before any command is executed

3. Byte stuffing (COBS)
- Consistent Overhead Byte Stuffing
- The packet delimiter byte (0x00) never appears inside the packet body
- Lets the receiver instantly re-sync if the line drops or picks up garbage bytes ^0B0Umtyh
