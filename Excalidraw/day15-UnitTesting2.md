TX Ring Buffer
- TX buffer is an async print queue. The code pushes bytes to the queue and DMA channel streams them to chunks when the hardware line is free

- tx_buffer[TX_QUEUE_SIZE]: the queue storage
- tx_head: points to the next free slot where uart_puts() will write the new byte
- tx_tail: points to the oldest byte not yet sent over the wire. Advance only if the DMA transfer complete interrupt 
- tx_busy: flag telling DMA transfer is active or idle
- tx_chunk_len: tracks how many bytes in the currently active DMA transfer chunk ^i3asbC0l

Operation

1. Enqueueing (uart_putc(char c)): put bytes into tx_buffer[tx_head] and advance tx_head. If queue is full, it waits in a loop while telling DMA to clear space

2. Kicking the transfer (uart_tx_kick()): if tx_busy is 0, and waiting bytes, it computes how many contaigious bytes can be sent. DMA cannot auto wrap around the end of an array in a single transfer. It splits wrapped data

3. Interrupt Cleanup (uart_tx_dma_done()): if DMA finish transmitting chunk, it triggers an interrupt. Advances tx_tail by tx_chunk_len. Sets tx_busy = 0 and calls uart_tx_kick() to flush remaining wrapped bytes  ^74qwCjcL
