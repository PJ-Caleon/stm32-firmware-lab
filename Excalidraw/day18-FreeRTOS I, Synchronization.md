What is a race condition?
- When multiple task access and modify shared data concurrently. Final result depends on execution timing ^LuOo2DMI

What is critical section and why keep it short?
- critical section are lines in code where it allows 1 thread at a time and locks other threads. (mutex). Other threads wait. It is kept short to avoid too much stalling  ^nw7zPKQF

mutex vs binary semaphore?

- mutex has ownership. The task that locked the mutex can unlock it 
- Binary semaphore is for synchronization. No ownership. ISR can release a semaphore  ^52DnZiuB

What is priority inversion and how does priority inheritance fix it?
- priority inversion is when a high priority is blocked by a lower priority tasked to release a shared resource
- the fix is to use priority inheritance where it temporarily release the hold to release the resource sooner. The priority returns afterwards  ^FqJvuHiW

What are the four conditions of deadlock?
- Mutual Exclusion - resource can be held by only one task at a time
- Hold and Wait - task holds one resource while waiting another 
- no preemption - resource can't forcibly taken away
- circular wait - task forms a cycle. Each waiting for a resource held by another  ^PJmRJQ0v

Why must ISR never block?
- these are interrupts which have the highest priority. Example scenario is a car about to crash. It must start the inflate safety. If the ISR is blocked, the balloon thing wont trigger ^pn1aIFDZ
