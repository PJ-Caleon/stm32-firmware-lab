Understanding I2C 
- Inter Integrated Circuit - communication protocol used to allow many device to communicate with each other using 2 wires 
- Short distance data communication 
- Sync master - slave protocol - both the master and the slave can send/ receive data
- Serial Clock (SCL); Serial Data (SDA) ^FfeIWiU7

Master ^JknKr4PK

slave ^6hzHWfqn

slave ^gNAqT47g

SDA ^vVJkjAqA

SCL ^0iujnBND

I2C Frame ^UHdyPPp1

Start Condition
- First pulls SDA low, then pulls SCL low  ^T9HFPqMy

Slave address 
- each i2c node has a fixed address
- 7 bits long, MSB first  ^aeoNbySY

Read/ write bit
- set by the master
- 0 = write
- 1 = read   ^bcTR5FT4

Ack bit
- sent by the receiver 
- 0 = ack 
- 1 = negative ack ^ULiOHLAd

Data byte
- memory contents of the address 
- 8 bit long, MSB
- every transmission is followed by an ACK bit ^Nb0vVIfD

Multiple data bytes
- multiple data can be sent and is concatenated after the first data and ack ^Jr8FBUi6

Stop condition
- SDA stays high
- SCL stays high ^kKKMhSU4

 Why open-drain with pull-ups? 
- Because the SDA and SCL remain as high, in order to tell them an event is occuring, we have to pull them down to ground  ^ed586JHn

What is clock stretching? 
- Clock stretching is when the clock width expands so that it can catch the data occuring in the i2c bus ^mnncmDF8

 How does a 7-bit address relate to the read/write bit?
- the read/write is located at the end of the 7 bit address. It tells the address if the method is to read or write to that address. A 0 bit is a write, while a 1 is a read  ^RAyhKw94
