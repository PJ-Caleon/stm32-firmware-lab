Bootloader Interrupt & Vector Table Handoff

- Issue: Stray interrupts firing during after the bootloader jumped to application due to unconfigured vector table offset. Peripheral interrupts left running

- Fix: Made sure interrupts are globally disabled during the handoff. Validated the application initial stack pointer and reset vector. Explicitly remapped vector table offset register at application startup ^u5LXMws4

Firware image Integrity & CRC checks

- Issue: the bootloader reliability validates the application image before executing a jump to prevent booting corrupted binaries

- Fix: verified the bootloaders runtime CRC calculation against expected header checksum to guarantee flash image integrity  ^IrMPAOQo

Stack Guard Init

- Issue: the stack guard filled RAM upward from __stack_limit to _estack, overwriting active stack frames and function return pointers with DEADBEEF. Causing immediate instruction access fault

- Fix: Rewrote the routine to capture the current stack pointer and fill downward strictly to unused free space below the stack pointer  ^1uMmBfql

Cortex M3 Hardware Constraint Mismatch (NOCP UsageFault)

- Issue: Code execution triggered NOCP cause unaligned block copies to invoke hardware floating point instruction on an FPU less cortex M3 core

- Fix: declared initialization sequence as static const and enforce strict float ABI settings to prevent instruction emission ^FNHTd1Aw

Unaligned Memory Access Trap in oled_refresh (UNALIGN_TRP)

- Issue: compiler optimized framebuffer to packet copying into 32 bit word stores at chunk_packet[1], tripping the core's strict unaligned access fault handler

- Fix: cast packet array access to volatile uint8_t * to bypass the block copy optimization and force 8 bit byte instructions ^VssOUWld
